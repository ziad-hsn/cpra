# Code of conduct

Treat people with respect in issues, reviews, discussions and other project
spaces. Discuss the code and evidence directly; explain disagreements without
personal attacks. Welcome questions and corrections, credit other people's
work, and respect requests to stop unwanted contact.

Harassment, threats, discriminatory abuse, sexual harassment, impersonation
and sharing another person's private information are unacceptable. Do not use
project spaces to advertise or contact participants after they have declined.

Maintainers may remove inappropriate content, close a discussion, restrict
participation or block an account. They should explain an action when doing so
does not expose private information or put someone at risk. Reports are handled
with discretion, and retaliation against a person raising a concern is itself
a violation.

For a public-space incident, use GitHub's report controls or ask a maintainer
for a private contact without posting personal details. For a security issue,
use the separate procedure in [SECURITY.md](SECURITY.md). This policy applies to
project spaces and to people representing CPRa; it is not a claim that the
project can moderate unrelated private activity.
