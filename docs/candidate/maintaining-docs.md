# Maintain candidate documentation

Follow the shared [documentation maintenance guide](../maintaining-docs.md). Candidate Markdown is canonical under `docs/candidate/` on main and copied to the same relative section on gh-pages. Record the exact reviewed candidate commit separately from the current-main runtime and documentation commits. Preserve the candidate scope notice when importing changes from another branch.
