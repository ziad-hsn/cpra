# License and project scope

CPRa application code is free software under the MIT license. The LICENSE
included with the selected source or distribution states its permissions,
notice requirements and warranty terms.

The embedded dashboard includes dependency notices. Packaged binaries include
target-specific dependency notices; third-party license obligations remain
separate from CPRa's code and artwork licenses.

CPRa-authored artwork by Ziad Hassan is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), with credit and an
indication of changes. See the [artwork attribution and name-use note](https://github.com/ziad-hsn/cpra/blob/main/brand/ATTRIBUTION.md)
and [complete license](https://github.com/ziad-hsn/cpra/blob/main/brand/LICENSE).
The name-use note does not add copyright restrictions. Code remains MIT and
third-party assets, including fonts, retain their own licenses.

This documentation describes a self-hosted infrastructure monitoring and recovery application. Read the [current boundaries](../release-notes.md#current-boundaries) and [deployment guide](../how-to/deploy-to-production.md) when deciding where to use it.
