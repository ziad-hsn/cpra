## Shared request rules

Every method takes `context.Context` first. Authenticated v2 requests require HTTPS by default. Redirects and automatic mutation retries are disabled. `Config.AllowInsecureHTTP` explicitly permits the configured origin. Ordinary requests default to ten seconds and a 64 MiB decoded-response ceiling.

`Response[T]` keeps `Data`, `ResourceVersion`, `RequestID`, `OperationID`, `StatusCode`, and `RetryAfter` separate. Pass the version you inspected to conditional changes. List calls default to 100 items and reject limits above 500. `Iterate` retains one page. Unknown driver observations are readable but cannot be blindly reapplied.

Errors support `errors.Is` for conflicts, missing resources, unavailable features, expired operations, authentication, invalid input, oversized responses, and ambiguous mutations. Use `errors.As` for structured `*cpra.Error` details; avoid logging server detail or credential-bearing payloads. A cancelled wait does not cancel the server operation.

## Streaming Prometheus export

`Client.Prometheus(ctx context.Context, w io.Writer) error` streams `GET /metrics` into a caller-owned writer. It is a handwritten helper outside the 82 generated v2 operations. The SDK closes the HTTP response body and leaves the writer open. Cancellation and the configured response-byte ceiling apply; an error can leave a partial export in the writer. Discard that partial output when the export must be complete.

`Client.Metrics(ctx)` instead decodes the structured `GET /api/v2/metrics` response. Use it for typed observations; use `Prometheus` when you need exposition text.
