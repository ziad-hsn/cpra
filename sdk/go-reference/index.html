    ErrDuplicate     = errors.New("execution already recorded")
    ErrStorage       = errors.New("worker journal durable write failed")

    Handler¶

    Build requirement: externaljobs.

    Handler returns the server-owned outcome envelope. Execution identity, grant, and kind are filled by the runner, never taken from handler output. Errors are intentionally not serialized: they may contain provider credentials.
