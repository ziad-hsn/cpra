    SDK wire types¶

    Generated by python3 scripts/sdk/reference.py. Do not edit generated tables.

    These are the SDK candidate contracts. The current CPRa application serves v1 read-only endpoints; its v2 management and worker servers are not implemented. A listed SDK method is not evidence of a deployed server route. See the guide for runnable local examples.

    Schema input SHA-256: 71723960b55145b57009faa9daa7fede20b08d85117171474b7c0631b4eb4977.

    Optional fields use Go pointers where omission differs from an explicit zero or false. Merge patch uses JSON null to request deletion where permitted. Duration fields retain Go duration strings such as 60s. Resource ID, incarnation UID, resource version, control revision, incident ID, and execution ID have different meanings; never substitute one for another.

    The descriptions below reproduce the schema contract. Inline nested shapes are included as JSON so no driver field is hidden by a summary table. externaljobs types are absent from default generated SDK packages.
