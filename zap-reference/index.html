    Source: https://context7.com/uber-go/zap/llms.txt

    Illustrates a complex Zap logging setup using zapcore to direct logs to multiple destinations (files and console) with different encoders and level filtering. Includes error level filtering and caller information.

    package main

import (
    ""os""
    ""go.uber.org/zap""
    ""go.uber.org/zap/zapcore""
)

func main() {
    // Define level enablers
    highPriority := zap.LevelEnablerFunc(func(lvl zapcore.Level) bool {
        return lvl >= zapcore.ErrorLevel
    })
    lowPriority := zap.LevelEnablerFunc(func(lvl zapcore.Level) bool {
        return lvl < zapcore.ErrorLevel
    })

    // Configure outputs
    consoleErrors := zapcore.Lock(os.Stderr)
    consoleInfo := zapcore.Lock(os.Stdout)

    // Create file outputs
    errorFile, _ := os.OpenFile(""/var/log/errors.log"", os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)
    infoFile, _ := os.OpenFile(""/var/log/app.log"", os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0644)

    // Configure encoders
    jsonEncoder := zapcore.NewJSONEncoder(zap.NewProductionEncoderConfig())
    consoleEncoder := zapcore.NewConsoleEncoder(zap.NewDevelopmentEncoderConfig())

    // Create cores for different outputs
    core := zapcore.NewTee(
        zapcore.NewCore(jsonEncoder, zapcore.AddSync(errorFile), highPriority),
        zapcore.NewCore(jsonEncoder, zapcore.AddSync(infoFile), lowPriority),
        zapcore.NewCore(consoleEncoder, consoleErrors, highPriority),
        zapcore.NewCore(consoleEncoder, consoleInfo, lowPriority),
    )

    // Build logger with options
    logger := zap.New(core,
        zap.AddCaller(),
        zap.AddStacktrace(zapcore.ErrorLevel),
        zap.Fields(zap.String(""app"", ""myservice"")),
    )
    defer logger.Sync()

    logger.Info(""info goes to stdout and info file"")
    logger.Error(""error goes to stderr and error file"")
}

perplexity,Zap SugaredLogger API methods Infof Debugf Warnf Errorf,"**Zap's `SugaredLogger` provides `Infof`, `Debugf`, `Warnf`, and `Errorf` methods for formatted logging at their respective levels, using a printf-style template and arguments.**[1][3]

These methods are part of the higher-level, more convenient `SugaredLogger` API, which wraps the structured `Logger` for less verbose usage with minimal performance overhead.[1][2][3] Obtain a `SugaredLogger` by calling `Sugar()` on a `Logger` instance, such as `sugar := zap.Must(zap.NewProduction()).Sugar()`.[1][3]

### Method Signatures and Usage[3]
All follow the pattern `func (s *SugaredLogger) <Level>f(template string, args ...interface{})`, where `<Level>` is `Info`, `Debug`, `Warn`, or `Error`.

**Examples:**
```go
sugar := zap.Must(zap.NewProduction()).Sugar()
defer sugar.Sync()

sugar.Infof(""Hello from Zap logger! The time is %s"", time.Now().Format(""03:04 AM""))[1]
sugar.Debugf(""Debug message: %s"", ""value"")[3]
sugar.Warnf(""Warning: %s failed"", ""operation"")[3]
sugar.Errorf(""Error: %v"", err)[3]

    Related Methods¶

    • <Level> (no f): sugar.Info(""msg"", key, value) for structured key-value pairs via Infow, Debugw, etc.[1][2][3]
    • <Level>ln: sugar.Infoln(""msg"", args...) for simple concatenated logging.[1][3]
    • Conversion: Use Desugar() to revert to structured Logger API.[1][3]

    These methods support all standard log levels (Debug, Info, Warn, Error, DPanic, Panic, Fatal) and integrate with With() for scoped fields.[1][2] Always call Sync() before program exit to flush buffered logs.[1][3]

    Usage Example¶

    Switch based on environment: 

    logger := zap.Must(zap.NewProduction())
if os.Getenv(""APP_ENV"") == ""development"" {
    logger = zap.Must(zap.NewDevelopment())
}
defer logger.Sync()
    This pattern is common for environment-specific logging.[1]

    Both write to stderr by default and support structured fields via zap.String(), etc.[1][5] For custom configs, use zap.NewProductionConfig() or zap.NewDevelopmentConfig().[3]
